# PNG to JPEG Drop

Node.js + Electronで動く、ドラッグ＆ドロップ式のPNG→JPEG変換アプリです。AppleScriptやAutomatorのワークフロー編集は不要です。PNGをアプリのウィンドウへドロップすると、JPEGを元PNGと同じフォルダに作成します。元PNGは削除しません。

## 起動方法

macOSにNode.js 20以上をインストール後、このフォルダで実行します。

```sh
npm install
npm start
```

npmキャッシュの権限エラーが出る環境では、プロジェクト内キャッシュを使います（macOS/Linux）。

```sh
electron_config_cache="$PWD/.electron-cache" npm install --cache .npm-cache
npm start
```

起動したウィンドウへPNGファイル、フォルダ、複数のファイル／フォルダをFinderからドロップしてください。初回起動時のみターミナルから`npm start`します。テストは`npm test`で実行できます。

## 変換仕様

- JPEG品質は画面のスライダーで1〜100に設定（初期値85）。
- サブフォルダ探索はチェックボックスで切替（初期値オフ）。
- `sharp`のMozJPEGエンコードオプション（`mozjpeg: true`）を使用。
- PNGの透明部分は白背景に合成。ピクセル寸法を維持。
- 出力名は元のベース名 + `.jpg`。
- 同名`.jpg` / `.jpeg`は大文字小文字を区別せずスキップ。既存ファイルは上書きしません。
- 一時JPEGを元ファイルと同じフォルダに生成・検証してから、原子的なハードリンク作成で確定します。失敗時は一時ファイルを片付けます。
- 隠し項目とシンボリックリンクは除外し、重複パスを1回だけ処理します。
- 変換は逐次実行し、完了数と個別エラーを画面に表示します。

MozJPEGは、画質を保ちながらJPEGをより小さくすることを狙ったエンコーダーです。出力サイズは画像内容と品質設定に依存し、常に小さくなる保証はありません。`sharp`の配布バイナリがMozJPEGオプションを提供します。

## テスト

`npm test`は一時ディレクトリに画像を生成して、JPEG形式・寸法・透明部分の白合成・日本語パス・既存ファイル保護・隠し項目除外・再帰探索・重複排除を確認します。GUI自動テストではなく、変換コアのNode.jsテストです。

## 注意点

このプロジェクトでは、設定保存、進捗／キャンセル、容量チェック、ログ、エイリアス判定は対象外です。Finderのタグや不可視属性に基づく除外はしません。ネットワークドライブや書き込み権限のないフォルダでは変換失敗として表示されます。
